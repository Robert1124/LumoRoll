# App Asset URL Resolver

## Purpose

Resolve app-owned relative asset paths into safe local file URLs rooted at `AssetStore.rootURL`.

## Inputs

- Relative paths stored in manifests or returned by staging services.
- App-owned URLs that need to be converted back to relative metadata paths.

## Outputs

- Local file URLs under `Application Support/LumoRoll/`.
- Root-relative metadata paths such as `film-rolls/<roll-id>/reference/original.jpg` or `tmp/imports/<import-id>/original.png`.

## Data Dependencies

- `AssetStore.rootURL`.
- Path components generated by storage, processing, or import services.

## Relationship To Other Modules

- Lives in `LumoRoll/SystemIntegrations`.
- Used by `PhotoImportStagingService` before writing staged imports.
- Used by `LocalPhotoImageLoader` before reading display images.
- Does not present UI, request permissions, decode images, mutate manifests, or write to Photos.

## State Management

The resolver is stateless and `Sendable`. It validates each path on demand.

## Error States

- Empty path.
- Absolute path.
- `file://` URL string.
- `..` traversal or malformed path component.
- URL outside `AssetStore.rootURL`.

Invalid paths throw a typed storage failure before file I/O occurs.

## Empty States

No empty-path success state exists; empty input is always invalid.

## Future Extension Points

- Centralize additional app-owned cache folder policies.
- Add migration-aware path rewriting if future storage layouts change.
